## 实现结果

320 × 480 pt 原生 NSPanel 窗体，12 pt 圆角，macOS 系统阴影；绘制工具栏线图、虚线内容区与参考图空状态。主文字使用 PingFang SC Semibold 20 pt；副标题14 pt、标签12 pt。按用户后续要求，参考图只用于外观，品牌及聊天拖入/隐私宣传文案已替换为“让常用内容触手可及 / 专注眼前，随时查看”。真实文本及原生按钮保留可访问性，不将参考图铺作背景。

[实际原生视图渲染](../design/window-render.png)为最终代码在 AppKit 中输出的 320 × 480 PNG，只包含窗口本体，不含 WindowServer 合成的外部阴影。

## 边界

- 当前复刻外观与既有窗口操作；三类内容提示仅作静态 UI 展示，未实现第三方业务对接，没有伪造业务成功状态。
- 7个工具栏按钮为原生控件：眼睛=边缘唤醒、图钉=锁定穿透、减号=收起到菜单栏、叉=关闭。前三个内容类型图标是静态提示。
- 最终渲染已比对位置与灰度；不同系统的字体字形、抗锯齿和系统阴影不承诺逐像素一致。
- 临时预览宿主使用与应用相同的窗口代码；不将其普通 App 菜单当作正式 SwiftUI 菜单栏产品的完整验收。预览宿主通过退出命令关闭。
- 既有 M0 焦点、Space / Mission Control、完整资源生命周期等未完成项仍见[原验收记录](m0-acceptance.md)。此次外观验证不会替代这些要求。

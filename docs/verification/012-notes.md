## 当前边界

- 实机结论限于当前 macOS 26.6.2、Apple Silicon 和当前安装的微信输入法；未在 macOS 14、15、Intel 或其他输入法逐一复验。
- 未模拟断电、进程强杀或长时间磁盘挂起；异常中断只保证最近成功写入版本。原子写入和备份不等于完整历史或跨设备备份。
- 便签为本地纯文本，单张上限 1 MiB，没有云同步、富文本、附件、提醒或永久删除入口。
- 不保存窗口布局与页签排列；重启从最近便签继续，正文文件保留。关闭便签编辑页后不承诺保留该编辑器的撤销历史。

### 2026-11-06 当前 Release 资源基线

Apple M4，32 GiB，macOS 26.6.2。Release 应用包含 arm64 与 x86_64，包内文件合计 5.28 MiB。本机 arm64 Debug 包为 4.81 MiB。在同一 Release 进程中依次通过应用菜单和窗口按钮切换场景，切换后等待 1 秒开始采样，每秒读取一次物理内存占用（proc_pid_rusage 的 ri_phys_footprint）与 RSS，取中位数。CPU 取该段主进程用户态与内核态累计时间之和的增量除以墙钟时间，100% 为一颗核心。

| 首页静置 | 8 秒 | 21.64 | 87.2 | 0.018% |
| 开启边缘唤醒、窗口隐藏 | 8 秒 | 21.74 | 87.7 | 0.748% |

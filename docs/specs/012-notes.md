# Spec 012 · 便签

状态：首版已实现。用户已确认「规划并实现可用首版，测试后重启体验」，本轮投入预算两小时。以验收记录区分已验证与未验证能力。

## Problem Statement

在使用终端、看行情或读小说时，用户需要就地记下一段文字。打开完整笔记软件、维护标题和文件路径会打断当前任务；小窗又容易因关闭、穿透、自动隐藏或极小尺寸让内容丢失或找不到。

便签首先解决快速记录与可靠保存。它沿用 Oriel 的透明度、页签、穿透和边缘唤醒，不增加独立的便签模式或新的窗口管理体系。

## Solution

首页新增「便签」。首次打开直接获得一张可输入的空白便签；已有内容时打开最近编辑的便签；若它已在其他页签打开，新页签从空白草稿开始。第一行非空文字自动作为标题，不强迫用户额外填写名称。顶部只放列表、新建和更多入口，主体为原生纯文本编辑区。窗口始终保留常规工具栏。

首版提供多张便签、本地自动保存、标题与正文搜索、置顶、可恢复删除和 UTF-8 文本导出。正常保存不弹通知；尚未保存、保存失败和正在查看回收站的状态必须明确。删除进入回收站，首版不自动清理回收站。

## User Stories

1. N01 作为小窗用户，我希望从首页点击便签即可输入，避免先填写名称或选择文件。
2. N02 作为记录者，我希望第一行自动成为标题，让列表和页签能辨认内容。
3. N03 作为记录者，我希望创建多张便签并随时切换，让工作片段互不混杂。
4. N04 作为记录者，我希望停笔后自动保存，并在持续输入时周期保存，减少异常退出时的损失。
5. N05 作为记录者，我希望关闭页签、小窗或正常退出前完成保存，重新打开后仍能看到完整文字。
6. N06 作为中文用户，我希望拼音输入、选词、换行、emoji、选文、撤销重做和粘贴正常工作。
7. N07 作为查找者，我希望按标题和正文筛选便签，并快速清除搜索回到列表。
8. N08 作为经常查阅某张便签的用户，我希望置顶该便签，让它不会被最近编辑记录挤走。
9. N09 作为误操作用户，我希望删除后的便签进入回收站，能恢复原文和置顶状态。
10. N10 作为使用页签的用户，我希望切页后便签内容和光标位置不被重建；再次选择已打开的同一便签时回到原编辑页，避免出现互相覆盖的双编辑器。
11. N11 作为极小窗口用户，我希望在 120 × 90 pt 仍能输入、选便签、新建和退出列表。
12. N12 作为便签用户，我希望在编辑和切换内容时保留窗口工具栏及必要的便签操作。
13. N13 作为使用边缘唤醒的用户，我希望正在编辑或使用菜单、导出选择器时窗口保持可见；锁定后不再接收输入，也不抢下层焦点。
14. N14 作为遇到磁盘错误的用户，我希望未保存文字留在编辑器中，能重试或复制；不能看到虚假的“已保存”。
15. N15 作为希望带走记录的用户，我希望通过系统保存面板将当前便签导出为 UTF-8 TXT，而不改变原便签。
16. N16 作为整理便签的用户，我希望空白草稿不会在列表里越积越多，已有便签清空后仍保留其身份并支持撤销。
17. N17 作为恢复数据的用户，我希望一张便签损坏时其余便签仍可打开；可恢复的上一份副本有提示，损坏原件不会被静默抹掉。

## Implementation Decisions

### 交互与边界

- 首页四项内容为终端、小说、自选股、便签；常规尺寸使用紧凑的四项布局，最小尺寸保证四个入口仍能点击。保留已有图标风格与单行提示。
- 编辑页只有一行约 22 pt 的便签操作区：列表入口、可截断的标题、新建、更多。窗口很窄时收为一个便签菜单，不强行塞入四个按钮。内容区高度不足 68 pt 时改为左侧菜单与正文并排，搜索列表在 240 × 240 pt 浮层中打开，避免多页签占满最小窗口。
- 字号默认 13 pt，随内容透明度变化；使用系统字体及原生文字选择、滚动和输入法能力。文本无富文本格式，粘贴以纯文本为准，不执行内容中的代码或网址。
- 全空白的新草稿先保存在内存，首次输入有意义内容后加入持久化列表；离开未编辑草稿时丢弃。已有便签被清空属于一次正常编辑，不自动删除。
- 列表按“置顶优先、最近修改优先”排列，显示标题及单行摘要。搜索匹配标题和正文，大小写不敏感。无结果时给出清除入口；列表不因逐字输入而反复跳动当前编辑页。
- 删除采用移入回收站；恢复移出回收站。首版没有自动清理或永久删除按钮，不用额外确认框阻挡每次删除。
- 新建、列表/搜索、保存、撤销与重做按 macOS 编辑习惯工作。2026-11-10 修订（改造方案 D3）：⌘F 在当前正文中查找（系统查找栏，⌘G / ⌘⇧G 跳转），⌥⌘F 打开列表搜索，与系统备忘录一致；内容区不足 68 pt 高、便签在回收站中时，⌘F 改为打开列表搜索。快捷键只在当前便签页签有焦点且无系统面板时生效；不拦截终端或其他内容的同名快捷键。
- 同一张便签只挂接一个活动编辑视图。不同便签可放在不同页签；若在另一页签从列表选择已经打开的便签，定位原页签；新页签进入便签时，若最近便签已打开，则提供新的空白草稿。关闭页签不会删除便签。
- 显示成功与保存成功分开：保存状态只有在当前版本实际写入成功后才清除。失败时显示短文案「未保存」和重试，文本保持可复制。

### 保存与恢复

- 数据只保存在应用专属的本机 Application Support 目录，不依赖联网或新账号。使用独立 UUID 标识，不用标题作为文件名或主键。
- 每张便签为一份有版本号的独立记录，保存正文、创建时间、修改时间、置顶标记和删除时间；列表标题由正文派生。删除、恢复和置顶与正文采用同一份原子记录更新。
- 停笔约 300 ms 合并保存，持续输入最长约 2 s 保存一次；调度使用单调时钟。自动保存只写已提交的文字，不结束输入法的组合状态。关闭当前编辑页、关闭小窗、退出应用是立即保存边界。正常退出若保存失败，应保留编辑器并给出重试/导出路径，不能直接丢弃。
- 写入使用临时文件与原子替换。保留上一份成功版本用于损坏恢复；只在新版本成功后更新保存状态。重启按独立记录发现便签，一份损坏不能使整个列表失败。
- 突然断电或进程被强制终止时，只保证最近成功落盘的版本；不能把正常关闭保证写成强制退出零丢失承诺。
- 首版单张便签正文上限 1 MiB（UTF-8），用于约束同步关闭保存和极长文本布局。达到上限时保留原有正文、拒绝超出部分并明确提示，不能截断后假装保存成功。
- 格式升级按记录版本判断；未知新版本保持文件原样并报告，不能当空便签覆盖。回收站恢复仍保留 UUID，避免产生重复内容。

### 模块与系统适配

- 新增轻量本地便签存储模块，职责限定为记录、读写、搜索、排序、软删除和恢复；不复用小说的书籍格式，也不将正文写进 UserDefaults。
- 应用层便签工作区统一管理已打开文档、保存调度与保存错误；编辑会话只管理当前便签、搜索和列表/正文页面。以同一数据源更新标题，避免多个独立副本竞争写入。
- 原生 AppKit 编辑器负责输入法、撤销栈、选区与滚动，SwiftUI 负责紧凑列表和菜单。已有窗口行为模块继续拥有穿透、自动隐藏和几何状态。
- 退出检查必须覆盖菜单栏退出以及系统正常终止请求；只在通知“即将退出”时保存不足以拦截写入失败。
- 不新增远程服务或第三方库。开发与实机测试使用隔离目录、独立应用标识，不能往用户真实便签目录写测试内容。

## Testing Decisions

优先使用便签工作区的公开命令与只读快照验证完整用户流程，通过临时目录重建实例证明内容已落盘。测试不能只检查内存状态、计时器是否被调用或文件名存在。

| 验收 | 自动化证据 | 实机证据 |
|---|---|---|
| N01–N03、N16 创建与编辑 | 草稿不污染列表；有正文后产生稳定身份；清空旧便签仍保留记录 | 首页入口、中文输入、首行标题、快捷新建 |
| N04–N05 保存 | 同一便签连续编辑只恢复最新完整版本；立即关闭后重建可读；持续输入保存有上界 | 关闭页签、小窗与正常退出后重新打开 |
| N06 原生编辑 | Unicode 往返及大小上限按实际编码判定 | 拼音组合、选词、emoji、撤销重做、粘贴、滚动 |
| N07–N08 查找置顶 | 搜索正文与标题；置顶排序；编辑不丢置顶 | 列表无结果、清除、窄窗菜单 |
| N09 删除恢复 | 删除后普通列表消失、回收站存在；恢复保留内容与身份 | 删除当前便签、从回收站恢复 |
| N10 多页签 | 不同便签隔离；同一身份定位原编辑器，旧事件不能改新便签 | 两页输入不同内容、切换与关闭后重开 |
| N11–N13 窗口适配 | 关闭与切页的保存边界测试 | 280 × 360 与 120 × 90、编辑焦点、穿透解锁 |
| N14 失败处理 | 注入确定性的写入失败，保持旧落盘版本与最新内存文本；修复后重试成功 | 失败提示、复制/导出、正常退出不静默丢弃 |
| N15 导出 | UTF-8 内容逐字相等，取消不产生状态变更 | 系统保存面板及取消 |
| N17 损坏恢复 | 一份坏记录不影响另一份；有效备份可恢复且保留坏原件；未知版本拒绝覆盖 | 恢复提示可理解 |

测试参照现有小说存储的临时目录重建方式、应用会话的生命周期测试及窗口外观测试。按“一个失败场景 → 最小实现 → 通过”的纵向切片推进，不预先铺满全部未实现功能的测试。时间调度用可控时钟/显式保存边界验证，避免长时间真实等待。

## Out of Scope

云同步、多人协作、账号、跨设备历史、文件夹/标签树、富文本工具栏、Markdown 预览、图片附件、OCR、提醒通知、待办数据库、密码保险箱、AI 改写、全局快捷键，以及发布与推送。窗口沉浸模式已按用户要求移除。

## Further Notes

## 保存隔离与标题计算补充
关闭页签只提交并保存该页的便签，关闭小窗只处理该窗拥有的便签；其他窗口的保存错误不阻挡当前关闭。应用退出仍检查全部便签。局部保存不得清除其他便签的自动保存期限；错误定位限制在本次检查的文档中。标题只扫描到首个非空行，不遍历后续正文；同一小窗只订阅一次工作区标题变化，并合并同一轮事件中的刷新。

# Spec 013 · 主界面

## 问题与方案
2026-11-07 按用户纠正收窄职责：主界面仅管理小窗与全局设置，不展示或管理内容。终端、便签、小说、自选股和页签操作全部留在小窗。后续按 [Spec 014](014-multiple-windows.md) 支持多个独立小窗，每窗多页签。

## 实现决策
主界面只订阅窗口状态，不持有内容视图、页签投影或内容打开命令。全局设置仍提供默认值及本地数据备份；业务内容操作全部在小窗。数据导出为可读本地副本，按模块串行取有效快照，最后原子发布目录；不承诺跨模块同一瞬间的快照。导出附带说明，暂不提供一键恢复。主界面显示时启用 Dock，关闭后回到菜单栏常驻。

## 边界
不新增账号、云同步、开机登录项、沉浸模式及自动覆盖式恢复。现有阅读字体设置沿用，不扩展无关编辑器功能。

# Spec 006：紧凑布局

日期：2026-11-05。用户认可透明度效果，要求UI更紧致紧凑。本规格覆盖旧参考图的固定尺寸、留白和字号，保留当前功能、颜色、文案及透明度分组。

## 变化

| 项目 | 原布局 | 当前布局 |
| --- | --- | --- |
| 默认尺寸 | 320×480 | 280×360 |
| 内容起始/左右底边距 | y=40、8pt | y=34、6pt |
| 主插画 | 56×80 | 42×60 |
| 主标题/行距 | 20/28 | 17/24 |

顶部按钮点击区域、锁命中坐标公式、120×90最小尺寸不变。首页完整布局阈值改为内容宽240、高264；不足时仍显示插画。标准内容组240×240，在更大窗口中居中。缩小、隐藏、锁定、恢复和关闭继续使用既有状态机。

## 用户澄清：仅继续压紧设置弹窗

主窗口维持本轮既有280×360尺寸。本次仅改设置内容视图：228×64pt，每项名称、滑杆、百分比同排；两行中心间距28pt，滑杆96×22pt，数值区域36pt宽。相较224×116版本高度减少约45%。

标准构建通过。原生弹窗已检查为紧凑两行，背景/内容滑杆均可调至100%，设置保持可操作；没有增加设置项或修改透明度计算。


后续文案收紧：设置可见标签缩短为“背景”“内容”，名称区28pt，弹窗宽度缩至196pt；高度64pt、滑杆96pt与百分比36pt保持不变。辅助功能名称仍保留完整的“背景透明度”“内容透明度”。


## 设置小圆角

设置浮层使用8pt圆角、原生阴影的非激活子面板，替代系统NSPopover外壳；保持196×64pt及两行内容。靠设置按钮下方右对齐，并限制在当前屏幕可见区域内。主窗口圆角不变。

保留设置按钮再次点击收起、Esc收起、点击外部收起；窗口锁定/隐藏/关闭时一并收起并移除临时事件监听，展开时继续暂停自动隐藏采样判定。

标准构建通过；原生渲染确认两行与小圆角，背景50%/内容25%调节、Esc关闭及重新打开保留数值已验证。跨应用物理点击收起尚未实测：定向自动化输入未触发全局鼠标监听，不能据此宣称该项通过。


## 小圆点滑块

设置滑杆仅替换NSSliderCell的滑块绘制：8pt系统强调色实心圆点，按下略加深。原生轨道、命中区域、连续调节和辅助功能均保留。标准构建通过，原生截图确认圆点样式，数值设置及轨道点击到0%/100%通过；定向工具拖动未产生数值变化，不据此宣称物理拖动已验证。

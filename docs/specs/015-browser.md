# 浏览器页签

小窗首页新增「浏览器」，在当前页签内打开一个小型浏览器，参考 menubarX 的菜单栏网页体验。

## 行为

- 顶部为工具栏：后退、前进、刷新/停止、地址栏、「…」菜单；窗口窄于 200 pt 时隐藏前进/后退，窄于 150 pt 时隐藏刷新。加载中工具栏底部显示进度线。
- 地址栏外观：圆角浅灰底，空闲时只显示站点名（去掉 `www.`）并居中，https 站点左侧带锁；点击（首次点击即全选）或 ⌘L 后展开完整网址并全选，底变白并加描边；地址框窄于 120 pt（窗口约 226 pt 以下）时隐藏锁。工具栏按钮悬停有浅灰高亮，不可用时变淡，工具栏下方有分隔线。
- 地址栏输入：含 `http(s)` 的地址、`example.com`、`localhost:3000`、IP 直接打开（本机与 IP 用 http，其余补 https）；其他文本用必应搜索。`javascript:`、`file:` 等非网页协议拒绝（提示音）。Esc 还原当前地址。
- 新建浏览器页签显示内置起始页：收藏夹，没有收藏时显示常用网站。
- 页签标题使用网页标题；加载失败显示内置错误页并可重试。
- User Agent 可在「…」菜单切换：iPhone（默认，移动内容模式）、iPad、Mac Safari（WebKit 默认）、Mac Chrome，或「自定义…」输入单行文本（≤512 字符）。选择会保存并作为之后新开浏览器页签的默认值；已打开的页签只在自己切换时生效，切换后当前页面自动重新加载。旧版「手机版网站」开关的设置会迁移。
- 缩放 50%–300%，每个页签独立。
- 收藏夹最多 30 项，保存在 UserDefaults，所有窗口共享。
- 网页的 `target=_blank`/`window.open` 在当前页打开（不支持依赖弹窗回传的登录流程）；`data:` 地址不能作为整页导航；`mailto:` 等其他协议仅在用户点击链接时交给系统。
- 无法显示的内容或下载链接保存到「下载」，同名自动加序号，完成后在 Finder 中显示；下载失败时弹出提示并删除残留文件；关闭页签会取消进行中的下载。
- 浏览数据（Cookie、登录状态、缓存）持久化并由所有浏览器页签共享；菜单「清除浏览数据…」全部清除。
- 快捷键：⌘L、⌘R、⌘D、⌘+（⌘⇧= 或 ⌘=）/⌘-/⌘0、⌘A/C/X/V/Z（转发给地址栏或网页）、⌘[ / ⌘]。
- 地址栏或网页内的输入框（含登录表单、可编辑区域）获得焦点时，边缘唤醒不会隐藏窗口。
- 页签切走、退回首页后，该页的媒体播放会暂停；切回页签时键盘焦点在网页上。
- 收藏已满（30）或页面不是网页时按 ⌘D：已满弹出提示，其他情况提示音。收藏写入失败不会清空已有收藏。
- 网页内容进程反复崩溃时最多自动重载 2 次，之后显示错误页。
- 支持网页的 JS `alert/confirm/prompt` 与文件选择（上传）。

## 不做

标签内多页签、历史记录、密码管理、内容拦截、网页内查找、摄像头/麦克风/定位授权。

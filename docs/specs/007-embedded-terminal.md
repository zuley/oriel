# Spec 007 小窗终端

首页第一张卡片为“终端”。点击卡片，在同一小窗的内容区打开当前用户的交互式登录 Shell，从用户主目录开始。紧凑首页以终端图标作为入口。终端与页签栏之间留 4 pt 间距，黑色背景左右及底部贴边，终端内容四周留 4 pt 内边距。返回首页时恢复首页边框。

| 操作 | 预期结果 |
| --- | --- |
| 使用 macOS 默认 zsh 提示符 | 主目录显示 `~ %`，进入项目目录后显示目录名和提示符，如 `oriel %`。用户自定义提示符优先 |
| 首次点击终端 | 创建一个伪终端，键盘焦点进入终端，可执行命令并读取输出 |
| 返回首页，再点终端或前进 | 回到同一会话，保留工作目录、变量和运行中的命令 |
| 收起、隐藏或锁定小窗 | 保留会话，隐藏或锁定时释放终端输入焦点 |
| 调整窗口尺寸 | 终端随内容区布局，向伪终端同步行列数 |
| Shell 自行退出 | 回到首页，下一次点击可创建新会话 |
| 关闭小窗或退出应用 | 挂断终端的 Shell 和当前前台任务，释放会话 |

2026-11-06 原生交互验证：从首页点击“终端”，执行算术表达式输出 `ORIEL-42`，`tty` 返回 `/dev/ttys003`。在 Shell 中设置变量，后退并再次点击“终端”后读取到原值。输入 `exit` 后回到首页，再次打开并运行 `sleep 120`。关闭小窗后，进程表确认本次 Shell 和前台 sleep 均已退出。

在缩小的首页点击中央终端图标，执行 `stty size` 得到 4 行 14 列。放大同一窗口后再次执行得到 19 行 32 列。标准 Xcode 构建、本地备用构建及 32 项核心测试通过。

2026-11-06 关闭会话回归：向前台进程组发送挂断信号后，保留 500 ms 供任务退出，再核对进程组与终端会话的归属并结束残留任务。应用退出时立即完成待处理的清理。两项真实伪终端测试覆盖了前台任务忽略 HUP、TERM 时的普通关闭和退出清理路径。

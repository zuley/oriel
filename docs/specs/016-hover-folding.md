# 小窗悬停展开

- 顶部新增「收起为横条」，开启后按钮名称变为「保持展开」，再点一次恢复固定展开。
- 开启后，指针移出小窗保持区（窗口外 8 pt）即折叠为 28 pt 高的工具栏；移入可见横条才展开。原内容区域不作为隐藏热区。
- 快速穿过横条并停在展开区域内时，依据相邻采样点之间的轨迹展开；从旁侧进入隐藏内容区或掠过整个窗口不触发。移动、切屏、模式切换和锁定时清除旧轨迹。
- 横条位置与展开宽高保留，屏幕下方空间不足时向上展开，收起仍回到原横条位置。窗口始终限制在横条所在屏幕的可用区域内；尺寸大于屏幕时适配可用区域。折叠不重建内容视图，不改变页签、文字内容、终端会话和阅读位置。
- 文字编辑、设置浮层、菜单、文件选择器、确认框及几何操作期间保持展开，结束后继续判断鼠标位置。
- 锁定时展开并保留原位解锁控制，解锁后继续自动折叠。收起到菜单栏与菜单恢复均清除自动折叠；关闭窗口移除采样监听。
- 自动折叠与边缘唤醒互斥，开启其中一种会退出另一种。窗口之间的状态、几何和采样保持独立。
- 120 pt 窄窗保留折叠按钮；眼睛按钮在窄于 180 pt 时收起，应用菜单中的边缘唤醒仍可使用。

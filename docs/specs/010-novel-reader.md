# Spec 010 · 小窗小说

在首页点击「小说」进入阅读区。每个页签拥有独立的阅读视图，所有页签共享此设备上的书与阅读位置。默认窗口内可以完成选书、阅读、换章与返回；极窄窗口优先保留正文和导航。沿用窗口透明度、穿透锁、页签关闭和边缘唤醒契约。

| 场景 | 操作与可观察结果 | 验证 |
|---|---|---|
| R01 本地导入 | 从系统选择器或拖放导入 TXT、无 DRM 的文字 EPUB。单本直接阅读，多本加入书架，并允许单独重试失败文件。保留书名、章节顺序、中文字符和段落。纯文本分卷保留卷名；仅列标题的目录不占用空白阅读页。移动原文件后仍能读。相同文件重复导入复用同一本。 | 包测试、系统文件选择器 |
| R02 在线书库 | 自选书源为 Project Gutenberg。书库内预置中文经典目录。点击某书才向镜像请求整本正文，首个镜像不可用时尝试备用。能取消，失败后可重试。 | 镜像实取、失败及取消检查 |
| R03 离线书架 | 导入或下载完整成功后原子加入书架。离线、重启后均能从书架打开。移除书前确认，保留用户原文件。 | 临时目录与重建实例 |
| R04 续读 | 按书籍身份保存章节和原文 UTF-16 位置，换章、改变字号、调整宽度与重新打开后能找回阅读位置。切回已有阅读页签，即使没有滚动，也以该页签的位置作为下次续读起点。 | 包测试、窗口实测 |
| R05 阅读 | 正文可以选中、滚动，可用目录直接跳章、按顺序换章、调整字号。保留书名和离开阅读的入口。 | 普通与紧凑窗口 |
| R06 失败与生命周期 | 空书、无法识别的格式或结构、过大文件有可恢复提示。EPUB 必读正文缺失引用或文件时整本导入失败，书架不留部分内容；明确标记的非线性项与导航项仍可跳过。取消打开文件或关闭页签时，迟到的任务不得重开旧视图。 | 异常输入测试、页签与菜单实测 |

书库收录十五部中文作品，含四大名著、明清话本与鲁迅短篇；书名和作者据 [官方离线目录](https://www.gutenberg.org/ebooks/offline_catalogs.html) 核对。保留书源版本原文和随书说明，下载后的正文与本地书共用阅读器。镜像来自 [Project Gutenberg 镜像目录](https://www.gutenberg.org/MIRRORS.ALL)。默认在设备内筛选十五本精选书。点「搜索全部中文藏书」或按回车才查询书源的中文 OPDS 目录，支持分页；选中一本才下载正文。EPUB 按 spine 顺序读取文字，忽略排版脚本和远程资源。支持 UTF-8、带 BOM 的 UTF-16 及常见 GB18030 中文 TXT。

## 读长篇时的导航

- R07 在阅读页查找正文，可按关键词列出匹配的上下文并跳到那一段。简体搜索能找到书源中的常用繁体写法；搜索在设备内运行，输入改变后丢弃过时结果。
- R08 可以将当前位置加入书签、从书签跳回或移除书签。书签保存在本机，重启可用；删除书时一并清除。字号与简体显示偏好全窗共享，阅读界面保持各页签独立。
- R09 书库支持按书名和作者筛选，分册与作者按照所选版本标注。初次进入显示可直接打开的书，已有藏书则从最近读过的书开始。默认展示原文，保留版本信息。
- R10 在桌面上打开阅读菜单、文件选择器或编辑搜索词时，边缘唤醒应允许完成当前操作。锁定后的自动唤醒保留下层应用焦点，穿透点击和滚动。
- R11 单窗最小尺寸为 120 × 90 pt。书架使用选书菜单，阅读页留下正文与省略号，目录、书签和查找结果可用原生菜单。阅读菜单可在常规尺寸主动进入专注模式。
- R12 修复损坏副本时，重新导入同一文件或重新下载同版书，成功后原子替换副本并保留身份与进度。各页签同步移除已删除的书。

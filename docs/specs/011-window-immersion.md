# Spec 011 · 小窗沉浸模式

**已撤销（2026-11-07）**：用户要求移除沉浸模式。入口、快捷键、悬浮退出及专用拖动逻辑均移除。以下为历史规格，不再代表当前产品。

用户决定移除小说专属的阅读模式，改为整个小窗通用的沉浸模式。模式只影响窗口工具栏和页签；小说、终端、行情、网页及首页沿用自己的内容与操作，不产生第二套模式状态。

| 场景 | 操作与可观察结果 | 验证 |
|---|---|---|
| I01 进入与退出 | 点击顶部四角图标或 ⌘⇧I 切换。收起窗口工具栏与页签，正文铺满顶部，不保留工具栏占位。右上角退出图标默认不绘制、不拦截内容点击；触碰图标右上角 8 × 8 pt 区域后显示，移入按钮可点击，移开隐藏。也可按同一快捷键恢复。 | 原生窗口 |
| I02 窗口范围 | 切换页签、⌘T 新建页签、改变内容都保持该窗口的模式。新的独立小窗及重启后的窗口默认关闭沉浸。 | 原生窗口、窗口外观接口测试 |
| I03 内容连续性 | 不重新创建内容视图、不重启终端、不重载网页或书籍。内容区域顶部为 0 pt，保留原有内边距、透明度、内容控件与键盘操作。Esc 留给当前内容，不作为沉浸快捷键。 | 原生终端、小说、行情 |
| I04 极小窗口 | 120 × 90 pt 下触碰右上角仍可显示并点击退出图标。常规模式下空间不足会隐藏进入图标；可右键顶部空白区或用快捷键进入。 | 原生窗口、几何测试 |
| I05 拖动与穿透 | 沉浸时按住 ⌥ 在内容区域拖动窗口，不占用正文空间；普通点击、选文及原缩放热区保留。锁定时暂时恢复窗口工具栏，保留原位解锁按钮；解锁后按原模式恢复。锁定时不可切换沉浸。 | 原生窗口、状态布局测试 |
| I06 恢复设置 | 菜单栏的透明度恢复操作先退出沉浸，再显示设置；低透明度时图标沿用悬停恢复不透明行为。 | 实机与代码检查 |

沉浸状态属于 `MiniPanel`，由 `MiniWindowChromeView` 统一布局。小说会话不保存此状态，小说界面不再出现「阅读模式」或「专注阅读」入口。

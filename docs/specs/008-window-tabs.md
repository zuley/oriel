# 小窗页签

小窗从一个首页页签开始。顶部工具栏在窗口按钮右侧显示新建按钮「＋」。只有一页时收起整行页签，内容区紧接工具栏。打开第二页后显示页签栏，关闭到只剩一页时收起。多页时，鼠标移入某个页签时，只有该页签右侧显示关闭按钮「×」。移出即隐藏，标题与页签宽度保持固定。每个新页签从首页开始，拥有独立的导航历史和终端会话。

- 切换页签时，输入焦点随当前内容切换，后台终端继续运行。后台 Shell 退出只更新所属页签。
- 点击后台页签的「×」直接关闭该页，当前页继续接收输入。关闭当前页签后选择相邻页签，关闭最后一个时回到新的首页。关闭小窗结束全部页签会话。
- 小窗持有键盘焦点且没有文件选择器时，Ctrl+Tab / Ctrl+Shift+Tab 循环切换页签，⌘⇧] / ⌘⇧[ 同样可用。⌘1–8 选择对应位置，⌘9 选择最后一页。锁定时按键继续交给下层应用。
- 锁定、自动隐藏、透明度和窗口尺寸作用于整个小窗。放不下所有页签时，当前页带有下拉列表，剩余宽度优先容纳相邻页。可通过下拉列表选择全部页签，小窗口仍可新建、切换和关闭页签。

原生交互验证通过。两个终端分别保存了 first 与 second，切回时能够读取各自的值。关闭运行 sleep 的页签后，该 Shell 与前台进程退出，另一页的 Shell 继续接受输入。后台 Shell 退出时只有其标题回到首页。120 × 90 pt 窗口支持从下拉列表切换，⌘T 新建和 ⌘W 关闭最后一页也已验证。

已在原生预览中点击顶部「＋」新建页签，并用后台终端页签的「×」关闭该页。当前终端仍能读取原会话变量，关闭最后一页后出现新首页。

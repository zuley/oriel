# Spec 014 · 多个独立小窗

2026-11-07 用户要求已有小窗时仍能继续新建。本规格替代早期最多一个小窗的限制。

## 行为
- 状态栏与工作台的「新建小窗」始终可用，每次创建一个新的独立窗口，依次命名「小窗 1、2…」，本次运行不复用编号。
- 新窗使用全局默认尺寸与透明度，在鼠标所在屏幕内错开放置；每窗有独立页签、穿透、自动隐藏、透明度、终端与采样生命周期。
- 工作台只列窗口状态与窗口操作，不展示内容或页签。操作明确作用于所选行；关闭一窗不关闭其他窗口。
- 工作台显隐操作合并为一个按钮：可见时为「隐藏」，隐藏时为「显示」。显示沿用恢复行为（解锁并关闭自动隐藏）；透明度过低时同时打开透明度设置以便找回。工作台不提供锁定穿透、边缘唤醒开关，这两个功能在小窗操作。
- 状态栏可按编号找回窗口；设置中应用默认值前明确选择目标窗口，避免“当前小窗”歧义。
- 书架、便签、自选股数据共用。行情可见性按窗口独立持有；关闭一窗不停止其他可见行情窗口刷新。同一便签只保留一个编辑器，从其他窗口选择它会定位原窗口，防止编辑器视图被移走。
- 退出应用保存便签并关闭所有窗口及终端；窗口数量、位置和会话暂不跨重启恢复。

## 验证接口与验收
继续采用已确认的公开窗口行为接口测试边界，增加多窗口命令入口；原生适配另做实机检查。

| ID | 验收 | 方法 |
|---|---|---|
| W01 | 连续创建生成不同 ID；两个窗口存在时仍可继续创建 | 公开集合接口 + 原生菜单 |
| W02 | 显隐、锁定、自动隐藏、移动与恢复只影响指定窗口 | 集合接口 + 原生 |
| W03 | 关闭后旧 ID 的指针、恢复、几何事件无效；其他窗口及新窗口仍可用 | 集合接口 |
| W04 | 工作台多行、按编号恢复、关闭与明确目标的设置可用 | 原生 |
| W05 | 同一便签跨窗打开定位原窗，原文字与撤销不被释放 | 便签接口 + 原生 |
| W06 | 行情在任一可见股票窗中继续刷新，退出后全数结束 | 既有可见性测试 + 生命周期检查 |

## 工作台悬停定位
- 悬停可见小窗所在行：目标加绿色轮廓并临时提高清晰度，其他可见小窗减淡至原窗口透明度的 22%。不激活目标、不获取键盘焦点，不改变配置、锁定和自动隐藏状态。
- 移开、切换工作台页面、主界面失焦/关闭/最小化时恢复原样。快速跨行时，旧行的退出不得清除新行高亮。
- 隐藏行不唤醒窗口，也不减淡其他窗口；目标隐藏或关闭时取消视觉效果。新建小窗遵循当前悬停效果。
- 通过公开窗口集合接口测试目标切换、退出、隐藏/关闭和状态不变；原生验证轮廓、透明度与恢复。

## 窗口重命名
工作台名称旁提供铅笔入口，弹窗编辑并保存或取消。名称不可为空，规范化空白后最多 32 个字符；工作台、原生窗口标题、恢复菜单、窗口命令菜单及设置目标列表同步更新。名称可重复，窗口操作仍按 UUID 定位。取消不修改，不影响内容、锁定、显隐、透明度与悬停；名称随窗口存活，本轮不新增跨重启恢复。

小窗顶部工具栏同步展示名称，占用新建页签与右侧控制之间的空白，不增加工具栏高度。名称单行省略，原生 tooltip 展示完整名称；名称区域仍支持拖动。名称跟随背景透明度；极窄窗口可用空间不足 24 pt 时隐藏名称，优先保留控制按钮。

双击小窗顶部名称可直接打开重命名弹窗，预填并选中当前名称；保存、取消、空白和长度校验与工作台一致。单击不打开编辑，拖动名称仍移动窗口。锁定时不响应改名；弹窗打开期间暂停边缘自动隐藏，关闭弹窗后恢复原设置。外部隐藏、锁定或关闭窗口时取消弹窗，不提交草稿。

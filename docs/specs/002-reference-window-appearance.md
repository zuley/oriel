# Spec 002：参考图窗口外观

最新紧凑布局修订见[Spec 006](006-compact-layout.md)：默认280×360pt、工具栏与首页间距收紧；该规格覆盖本文旧默认尺寸/外观坐标，历史测试坐标及证据保留。

日期：2026-11-05。依据：用户提供的 350 × 510 px 截图，并明确要求窗口样式“一比一复刻”。这是现有 M0 的外观变更，不是新的视觉方向探索。

用户后续明确：参考图仅约束视觉，移除原品牌文案，采用通用内容展示描述。主文案改为“让常用内容触手可及”“专注眼前，随时查看”；布局、控件和业务范围不变。原始参考图片保留。

2026-11-05 悬停提示补充：顶部图标移入约0.3秒后显示深色小提示，说明当前动作；禁用的前进/后退说明暂无可导航页面。移出、点击、拖动、缩放、锁定或隐藏窗口时取消提示。提示框不接收鼠标，不改变窗口焦点。按用户后续要求，文字始终单行完整显示，提示框按文字自然宽度展开，不折行；窄窗必要时减小提示外侧留白。原生构建与提示渲染检查通过，真实鼠标停留触发待实测。

2026-11-05 窗口控制样式修订：收起与关闭改为macOS经典交通灯样式，分别为黄色与红色12pt圆点，位于左上角，红色关闭在前、黄色收起在后（中心x=20、40）；各20×28pt点击区域无重叠。悬停显示减号/叉号，按下加深；锁定时两者置灰。黄色仍执行收起到菜单栏，不新增系统Dock最小化行为。构建与普通/锁定态原生渲染检查通过。

## 视觉基线

- 实际窗口本体 320 × 480 pt；参考图外围约 15 px 为阴影与留白，不计入窗口鼠标热区。此默认尺寸替代 Spec 001 初版的 320 × 240 pt。小屏仍以当前屏幕可见区域为上限。
- 固定浅色背景、8 pt 外框圆角，外沿仅保留 4 pt 的淡投影，四边采用相同的向外淡出效果，随背景透明度减弱；不用系统标题栏和红黄绿按钮。像素核对表明参考图直边没有实心外描边，不额外增加灰色边框。
- 顶部工具栏高40pt：左侧关闭、收起；常规宽度继续排列后退、前进，右侧为眼睛、设置、锁。初始后退/前进灰显。该排列按用户macOS习惯要求替代参考图原顺序。
- 无描边内容区位于 (8,40)，大小 304 × 432 pt，圆角约 8 pt；底部保留 8 pt。
- 中央空状态采用两行主文案：“让常用内容触手可及”“专注眼前，随时查看”。保留“或添加以下内容”及“聊天”“小说”“自选股”三个通用静态内容标签。使用真实文本、原生控件和矢量线图，不将整张截图用作背景。
- 锁定/自动隐藏开启时允许必要的按钮状态标识；默认静止状态对齐参考图。Hover、键盘焦点不改变基础布局。
- 窗口圆角由原生视图与系统合成；不同 macOS 合成器、像素缩放与字体抗锯齿可能存在细微差异，须以实际渲染对照记录为准，不宣称未经测量的逐像素相等。

## 功能接入

- 默认显示原生首页。设置改为仅两项透明度控制，见[Spec 005](005-transparency-settings.md)；原M0网页入口与验收作为历史记录保留。
- 前进/后退连接本地网页浏览与首页；无可用历史时禁用。
- 眼睛切换边缘唤醒；锁图标切换锁定穿透。根据 [Spec 004](004-lock-recovery.md)，锁定且可见时原锁图标高亮，其余图标置灰；仅锁图标的28 × 28 pt区域可点击，该矩形接收鼠标，其余区域继续穿透；菜单栏“显示并解锁”仍可恢复。就地取消仅普通解锁，不关闭自动隐藏。
- 设置仅显示背景透明度、内容透明度两项，不含窗口操作、导航或验证网页入口；所有宽度一致，详见[Spec 005](005-transparency-settings.md)。
- 减号表示“收起到菜单栏”：保留窗口与锁定/透明度配置，设为隐藏并关闭自动隐藏，清除指针历史。鼠标不能唤醒，须由菜单栏恢复。
- 关闭按钮复用已验证的关闭命令，移除窗口并停止采样。
- 聊天、小说、自选股仍作为静态内容类型提示，本轮不实现对应内容功能，不提供虚假的加载或成功状态。

## 验证

- V01：320 × 480 原生视图实渲染，对照参考图核对边距、图标、字体与灰度；主文案按用户修订核对，不沿用图片中的品牌文案。
- V02：完整 Xcode 构建，核心测试回归。收起行为沿已确认的 WindowBehaviorController + snapshot 边界执行一次真实红绿测试。
- V03：原生工具栏可访问，调整菜单、验证网页导航、收起/恢复、关闭接入实际命令。
- V04：保持现有非激活显示、锁定穿透与边缘唤醒实现；M0 尚未完成的焦点/系统/资源验收不会因外观完成自动变为通过。

本轮不新增网络加载、多窗、持久化、发布或外部内容集成。后续用户指定的拖动、边缘缩放及响应式布局见 [Spec 003](003-move-resize.md)；320 × 480 仍是初始外观基线。

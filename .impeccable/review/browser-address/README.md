# 浏览器地址栏焦点布局修复

新建浏览器会在首次布局之前聚焦地址栏。原来的自定义单元格把文字绘制区域缩到自然行高，但编辑器仍可能被 AppKit 拉满 22 pt 控件高度，导致首次聚焦和编辑中缩放时文字向上偏移。

回归测试使用真实 NSPanel 和共享文字编辑器，对比文字像素在地址栏中的垂直位置。修改前稳定复现约 4 pt 偏移，证据见 `red.log`、`before-focused.png` 和 `before-idle.png`。

修复使用原生文字控件的自然高度，在 22 pt 地址栏内居中；首次聚焦前完成布局。外层空白仍可点击聚焦，无需自行修改共享编辑器的坐标。

验证：

- `BrowserAddressLayoutTests` 覆盖首次自动聚焦、120/180/280/480 pt 宽度、失焦、再次聚焦和地址栏外层点击。
- 完整 Xcode 测试：48 项通过，0 失败；日志 `.build/browser-address-tests.log`。
- `./scripts/build.sh`、签名严格校验、项目文件校验和 `git diff --check` 通过。
- 已重启最新应用，实际新建浏览器页签，输入 `example.com`（未导航），对比首次聚焦及再次聚焦的文字位置，确认居中稳定。验证输入已清理，保留首页和浏览器新页签。

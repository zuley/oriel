# 中性色为主、珊瑚色点缀 · 2026-11-09

用户明确要求保持原本简洁素雅的配色，主色仅作点缀。本轮恢复白色、浅灰与中性文字；移除桃色大底、暖棕正文、黄色页签底色和首页入口的常态主色。主要新建按钮、选中图标及下划线、焦点与少量控件状态保留珊瑚色。

### 背景回调与手型光标

常态底色调整为 field 向 sidebar 混合 25%（约 #F2F2F2），介于前两次背景深浅之间，高度仍为 72 pt。[常态](home-tile-cursor.png) 与 [移入状态](home-tile-hover.png) 为本轮实际截图。

常规宽度下，眼睛和设置按钮的区域从 28 pt 收为 22 pt，去掉两个额外的 2 pt 间隔，右侧组横向占位减少 16 pt；图标保持 14 pt。锁定仍使用固定的 28×28 pt 解锁区域，窄窗的 16 pt 控件保留原规则。实机效果见 [紧凑右侧工具栏](compact-right-controls.png)。

# Oriel · 半窗

一个常驻菜单栏的 macOS 小窗工具，可在独立页签使用终端、看自选股、读本地或在线小说、记录便签、浏览网页。小窗支持锁定穿透、边缘唤醒和透明度调整。

## 开发

需要 macOS 14+、支持 Swift 6 的完整 Xcode。打开 `Oriel.xcodeproj`，选择 Oriel scheme，或在仓库目录运行：

```sh
./scripts/build.sh
open .build/xcode/Build/Products/Debug/Oriel.app
```

脚本只为当前进程选择 Xcode，不更改系统的 `xcode-select` 配置。若 Xcode 安装在其他位置：

```sh
DEVELOPER_DIR=/path/to/Xcode.app/Contents/Developer ./scripts/build.sh
```

运行行为测试：

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcrun swift test --package-path Packages/OrielCore
swift test --package-path Packages/OrielReading
swift test --package-path Packages/OrielTerminal
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Oriel.xcodeproj -scheme Oriel -destination 'platform=macOS' test
```

只有 Command Line Tools 时，`./scripts/build-local.sh` 可尝试生成 `.build/local/Oriel.app`，仅用于本地验证；不能替代标准 Xcode 构建验证。

## 使用

启动后默认打开主界面，也可通过菜单栏 **Oriel → 打开 Oriel** 随时进入。关闭主界面不会关闭小窗或终端。

- **工作台**：小窗以真实内容缩略图展示，统一高度并保留各自宽高比；超宽缩略图可横向滚动。单击缩略图可显示或定位小窗，右键可显示／隐藏、重命名或关闭；双击小窗顶部名称也可重命名。锁定穿透、边缘唤醒仍在小窗操作。鼠标移到缩略图时，对应可见小窗高亮，其他小窗暂时减淡；移开恢复。
- 内容展示、便签整理、小说导入、行情操作及页签管理全部在小窗中完成，主界面不提供对应页面或快捷入口。
- **设置**：启动时是否打开主界面、新小窗的默认尺寸和透明度；选择目标并点击「应用到所选小窗」才会修改该窗口。鼠标移入小窗右侧“···”可展开功能图标，再移入设置图标即展示透明度面板；离开图标和面板后收起。
- **导出数据**：导出便签（含废纸篓和恢复副本）、书架、阅读位置/书签、自选股及应用设置到独立文件夹；不包含终端会话，暂不支持一键恢复。

[主界面规格](docs/specs/013-management.md) · [多窗规格](docs/specs/014-multiple-windows.md) · [多窗验收](docs/verification/014-multiple-windows.md)

**浏览器**：在新页签首页点「浏览器」。地址栏可输入网址或搜索词（非网址按必应搜索）；左侧为后退、前进、刷新/停止，右侧「…」菜单提供收藏、收藏夹、User Agent 切换（iPhone 默认，适合窄窗；另有 iPad、Mac Safari、Mac Chrome 和自定义）、缩放、在默认浏览器打开、拷贝链接和清除浏览数据。快捷键：⌘L 聚焦地址栏，⌘R 刷新，⌘D 收藏，⌘+ / ⌘- / ⌘0 缩放，⌘[ / ⌘] 后退／前进。网页内弹出的新窗口在当前页打开，下载保存到「下载」文件夹。所有浏览器页签共享登录状态；收藏夹不随「导出数据」导出。[规格](docs/specs/015-browser.md)

小窗操作：

1. 点击菜单栏 **Oriel → 新建小窗**。该菜单始终显示；已有小窗时仍可继续创建，每个小窗独立使用。
2. 新建默认显示内容展示首页。顶部设置仅包含 **背景透明度**、**内容透明度** 两个实时滑杆；向左调至完全透明，向右调至完全清晰。顶部按钮随背景透明度变化；内容透明度统一控制文字、插画、内容图标及装饰，设置浮层保持可见。
3. 开启 **锁定穿透**，鼠标点击和滚动将交给下面的应用。
4. 开启 **边缘唤醒**，离开窗口后隐藏，触碰原位置的边缘显示；进入内部保持显示。
5. 窗口隐藏或锁定时，选择 **Oriel → 恢复小窗**，选择目标小窗，即可显示、解锁并关闭自动隐藏。默认小窗与页签标题不附加序号，可按需重命名小窗。
6. 点击小窗左上角的红色按钮关闭小窗。**退出 Oriel** 释放窗口并退出菜单栏应用。

菜单栏始终提供 **退出 Oriel**。应用的标准 **小窗** 命令菜单提供完整管理操作，支持键盘与辅助访问。

小窗右侧展开后的 **悬停展开** 图标：开启后，移出小窗会收起为顶部横条，移入横条恢复原尺寸；关闭该开关可保持展开。输入、菜单和弹窗操作期间保持展开。自动折叠与边缘唤醒互斥，应用的小窗菜单也提供 **悬停展开** 开关。

窗口初始为 280 × 360 pt（紧凑布局），可同时创建多个独立小窗。未锁定时，拖动顶部空白区移动窗口，拖动四边或四角调整大小；最小 120 × 90 pt。缩窄后隐藏浏览图标；设置面板只提供两项透明度，首页空间不足时只显示居中图标；网页仍可在小视口内滚动。边缘唤醒区域跟随新位置与尺寸。实际拖动后的位置与尺寸不自动保存；新建尺寸可在主界面设置中指定。

默认首页不显示“+”；打开内容页后，页签栏中的“+”紧跟可见页签，短窗口则紧跟顶部页签切换器。右侧“···”默认收纳未开启的功能图标，鼠标移入后向左展开并淡出，收起后重新显示；已开启的折叠、边缘唤醒和所有桌面显示图标保持可见。锁定时解锁图标留在右侧。折叠图标切换悬停展开，眼睛图标切换边缘唤醒，叠放窗口图标切换当前桌面／所有桌面显示（新建小窗默认仅在当前桌面显示），锁图标切换锁定穿透；窄窗口展开时暂时隐藏左侧按钮以腾出空间。减号收起到菜单栏并停用自动隐藏，关闭按钮移除窗口。锁定后不能直接拖动或缩放，仍通过菜单栏“恢复小窗”恢复。

锁定时，**锁图标高亮，其他图标置灰**；再次点击锁图标恢复操作，保留边缘唤醒设置。只有锁图标区域接收鼠标，其余区域继续穿透。窗口隐藏时先触碰边缘唤醒，或通过系统菜单栏 **Oriel → 恢复小窗** 恢复（同时关闭自动隐藏）。

点击顶部工具栏的 **＋** 或按 **⌘T** 新建首页，点击页签切换。**Ctrl+Tab / Ctrl+Shift+Tab** 切换到下一页或上一页，**⌘1–8** 跳到指定位置，**⌘9** 跳到最后一页。空间不足时，从当前页的下拉列表选择全部页签。鼠标移入页签后，点右侧出现的 **×** 关闭该页，或按 **⌘W** 关闭当前页。关闭最后一页后回到新首页。各页签分别保留自己的阅读视图或终端会话。

点击首页的 **终端** 可在小窗内使用本机登录 Shell，初始目录为个人主目录。按 **⌘[** 返回首页，再点终端会继续原会话。输入 `exit` 返回首页，关闭小窗或退出 Oriel 会结束会话。窗口缩小时，首页保留终端、小说、自选股和便签四个入口。

点击 **自选股** 查看腾讯财经行情。按代码、名称或拼音搜索，点「＋」添加，点「我的自选」可移除。自选列表保存在本机。可见时每 30 秒刷新，短时间重新唤醒可复用刚更新的报价。搜索中点刷新会重试当前关键词。

### 小说

- **导入本地书**。将 TXT 或无 DRM 的文字 EPUB 拖到首页或书架，也可进入「小说」按 **⌘O** 选择文件。单本直接打开，多本加入书架。导入后可移动原文件。
- **在线找书**。书库内置十五部中文作品。输入书名或作者可筛选，按回车或点「搜索全部中文藏书」会查询 Project Gutenberg 的中文目录。点击作品后下载整部源版本，之后可以断网阅读。
- **续读与找回原文**。书架按最近阅读排序。小窗记住章节和段落位置，**⌘F** 查找正文，**⌘D** 添加书签。阅读设置里可以调字号、切换简体。
- **翻页**。滚动或按空格向后翻页，**⇧空格** 向前翻页。到章末后再次按空格进入下一章。**← / →** 切换章节，底部目录可以直达指定章节。极小尺寸时从省略号菜单操作。

书籍与进度保存在本机。单份导入上限为 32 MiB，EPUB 按正文顺序提取文字。在线原文与版本说明可从阅读设置查看。[小说规格](docs/specs/010-novel-reader.md) · [实机验收与性能记录](docs/verification/010-novel-reader.md) · [书源目录](https://www.gutenberg.org/ebooks/offline_catalogs.html)

### 便签

点击首页 **便签** 即可输入，第一行自动成为标题。停笔约 300 ms 自动保存，持续输入最长约 2 s 保存一次；关闭页签、小窗或正常退出前立即保存。后台保存不会打断输入法选词。

- **⌘N** 新建便签，**⌘F** 在当前便签正文中查找（**⌘G / ⌘⇧G** 下一个／上一个），**⌥⌘F** 打开列表搜索标题或正文、回车打开首个结果，**⌘S** 立即保存。内容区不足 68 pt 高时 ⌘F 改为打开列表搜索。正文支持 **⌘Z / ⌘⇧Z** 撤销与重做、选文及纯文本粘贴。
- 更多菜单可置顶、复制全文、导出 UTF-8 TXT，或移到回收站。回收站中的便签可恢复，首版不自动清理。
- 不同页签可编辑不同便签；从列表选择已打开的便签会定位原页签。新页签进入便签时，若最近一张已打开，就提供空白草稿。
- 最小窗口将操作收进侧边菜单，搜索列表在浮层中打开。便签沿用窗口透明度和穿透。

数据在本机 `~/Library/Application Support/app.oriel.mac/Notes/`，单张上限 1 MiB。每张记录独立原子保存，并保留上一份成功版本；损坏原件保留在 `Recovery`。保存失败会保留正文并阻止正常关闭，可重试、复制或导出。强制终止和断电只保证最近成功保存的版本。

[便签规格](docs/specs/012-notes.md) · [任务计划](docs/plans/012-notes-tasks.md) · [验收记录](docs/verification/012-notes.md)

终端模块使用 [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm) 1.10.1。EPUB 读取使用 [ZIPFoundation](https://github.com/weichsel/ZIPFoundation) 0.9.20。首次构建需要联网解析 Swift Package 依赖。

边缘热区内外各 12 pt。开启边缘唤醒时，鼠标移动事件在 25 ms 内合并采样，静止时每 250 ms 复核；事件监听安装失败时回退到 30 ms 采样。终端、便签编辑器，或小说、股票搜索框拥有键盘输入焦点时，移出鼠标仍保持显示。除了直接命中边缘，同一窗口相邻两次实际采样从外扩保持区外进入区内时，也会补发唤醒，覆盖采样直接落到中央的情况。

没有采样历史时，首次落在中央不会唤醒；两次采样都在保持区外也不会显示，即使两点间的线段穿过窗口。关闭、恢复或切换自动隐藏会清除历史，旧窗口的采样不会影响新窗口；自动隐藏开关读取的位置只决定当下显隐，不作为连续采样历史。

2026-11-05：根据用户实测的卡顿、不灵敏和偶发漏触发反馈修订上述规则。修复后用户确认慢速、快速唤醒均正常；当时的记录保留在 M0 验收文档中。2026-11-07 的小说验收补测了锁定状态下边缘唤醒后的跨应用键盘输入。
